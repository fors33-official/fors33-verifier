# Security policy

Report vulnerabilities in Fors33 Verifier privately. Do not open a public GitHub issue for a security report.

Use [GitHub private vulnerability reporting](https://github.com/fors33-official/fors33-verifier/security/advisories/new) on this repository.

Include steps to reproduce, affected versions, and any mitigation you already have.

## Supported versions

Security fixes are applied to the latest published `X.Y.Z` release on PyPI and the matching Git tag `vX.Y.Z`.

Older minor lines do not receive backports unless a fix is cut as a new patch tag.

## Response

We aim to acknowledge a report within 7 days and to ship or decline a fix within 90 days, coordinated with the reporter before public disclosure.
